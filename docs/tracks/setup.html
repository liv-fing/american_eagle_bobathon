Environment Setup
Connect to your IBM i, install the required extensions, and confirm your assigned library number before starting the exercises.
Action required: in step 0.3, choose your server and click the table row with your assigned library number. This updates the server IP, key file, library, port, and prompts throughout the guide.
~15 min Required
Complete all steps below before starting any exercise. Start by installing and logging in to Bob, then verify your extensions, find your library number, and finally connect to IBM i.
0.1 — Prerequisite Bob Setup

Check your inbox for the "You've been invited to join your team" email, then follow these steps to install Bob and sign in for the first time.

1
Create your IBM ID
Open the invitation email and click the link to create your IBM ID. This gives you an account to access IBM Bob.
2
Download & open Bob
Download Bob using the correct installer for your computer, then open it. If Bob asks whether to import settings from another editor, select your regular IDE or click Skip for now. If it asks about chat migration, click Skip migration.
3
Log in to Bob
In the Bob chat window, click Log in to Bob. When asked to allow Bob to sign in, click Allow. Bob will then ask if you want to open a link — click Open. This opens your browser to complete the sign-in.
4
Verify your account is active
Click the gear icon above the Bob chat window. If the chat window isn't open, click the Bob icon to the right of the center search bar to open it first.
Open Bob settings with the gear icon above the chat window
Under the General tab, confirm that coins are listed in your budget at 100% remaining — this means your account is active and ready. You're all set even if you don't see a team name matching the screenshot below.
💡 Team dropdown: If you have used Bob before and belong to multiple teams, a team dropdown will appear — make sure it shows a team with Bobathon in the name. If you only belong to one team, the dropdown may not be visible at all, which is expected.
If a team dropdown appears, select the Bobathon team
0.2 — Verify and Install Required Extensions

Two extensions are required. The IBM Bob Premium Package for i is often pre-installed for your team — verify it below. The IBM i Development Pack must be installed manually.

1
Open the Extensions view
Click the Extensions icon in the Activity Bar — the vertical strip of icons on the far left side of Bob — or press Cmd+Shift+X (macOS) or Ctrl+Shift+X (Windows/Linux) to open the Extensions panel.
Click the Extensions icon in the Activity Bar to open the Extensions panel
2
Verify IBM Bob Premium Package for i
Search for "IBM Bob Premium". If IBM Bob Premium Package for i (publisher: IBM) appears with an Install button on the right, click Install now. If there is no Install button, you're all set — skip to step 3. This package includes Code for IBM i (source editing, object browser, IFS browser, Db2 for i, and more).
Search for "IBM Bob Premium" — an Install button on the right means it still needs to be installed
3
Install IBM i Development Pack
Just like the previous step, search for "IBM i Development Pack" in the Extensions panel. This extension is not pre-installed — click Install if it does not appear under Installed. Reload Bob if prompted.
4
Open Bob Settings
Click the Bob Settings button in the bottom-right corner of the Bob IDE to open the Settings panel.
Click Bob Settings in the bottom-right corner of the Bob IDE
5
Install Premium Package for i
Further down the panel, next to the Add ons setting, you should see IBM Bob Premium Package for i. Click Install. Bob may ask you to restart the IDE — if so, accept and restart.
Click Install next to IBM Bob Premium Package for i under Add ons
6
Confirm it is activated in Bob
Now click the icon in the very top-right corner (shown in the first screenshot below) to return to your Bob chat. From there, click either Agent or the + sign, and you should see the IBM i Developer and IBM i Database modes listed as options. If they don't appear, your IBM Bob account likely hasn't been linked to your Premium Package for i entitlements yet.
Click the icon in the top-right corner to return to the Bob chat
IBM i Developer and IBM i Database appear in the mode list

0.4 — Connect Bob IDE to IBM i
1
Add a new connection
Click the IBM i icon in the Activity Bar (shown circled in red in the screenshot below), then click New Connection. Enter the host IP <myIPaddress>, the user profile ITZUSER, and the ae_<server>_key.pem private key provided in the Box folder↗. When prompted for the private key, browse to the downloaded ae_<server>_key.pem file on your computer. Do not use the password here — use only the ae_<server>_key.pem private key file.
Click the IBM i icon in the Activity Bar
IBM i connection panel
💡 If you get a private key error when connecting, see 0.5 for instructions on setting the correct file permissions on ae_<server>_key.pem.
2
Add your assigned library to the User Library List
In the Code for IBM i extension (arrow in the picture below), navigate to the User Library List section and click the + icon. An input field will pop up at the top of the screen — type FLGHT4nn and press Enter. You'll then see your library added to the list. Remember: no "I" — it's FLGHT, not FLIGHT.
Navigate to User Library List and click the + icon
Type FLGHT4nn and press Enter to add your library
✅ If you have a 5250 terminal, you can also add the library with: ADDLIBLE FLGHT4nn and launch the app with: GO FLGHT4nn/FRSMAIN
3
Add your assigned library to the Object Browser
While still in the Code for IBM i extension, go to the Object Browser section and click the funnel icon or the Create new filter button.
Object Browser — click the funnel icon or Create new filter
Name your filter (e.g. your assigned number). In Libraries, enter your assigned library FLGHT4nn. For Object types, change it to *ALL to see all object types: *PGM (RPG and CL programs), *FILE (display and database files), *MENU (application menus).
⚠️ Use *ALL, not * — the wildcard * does not work for filtering object types in the Object Browser. You must type *ALL exactly.
Enter FLGHT4nn as the library and choose your object types
Scroll down and click Save Settings. Your named filter will now appear in the Object Browser, and you can navigate and expand the members inside your library.
4
Set the workspace to Library List
Throughout the labs you'll see references to setting the scope or workspace to QSYS or your Library List. This is because Bob can work on local files on your laptop and on the IBM i you just connected to — all the labs focus on the IBM i.
Click the + icon above the Bob chat window. When the options appear in the center of the screen, make sure your library is listed under New Task in Library List and select that option.
Select "New Task in Library List" — confirm your FLGHT4nn library is listed
Verify the chat scope shows Library List
0.5 — Set Private Key Permissions

Download your private key from the Box folder and set its permissions so OpenSSH will accept it. You need this to connect Bob to IBM i in 0.4 and to open the SSH tunnel in Exercise 4.

1
Download the private key from the Box folder
From the Box folder↗, download your private key file, then set its permissions so OpenSSH will accept it.
macOS / Linux — run in Terminal:
chmod 600 ae_<server>_key.pem
Windows — run in PowerShell (run as Administrator if the command fails):
icacls ae_<server>_key.pem /inheritance:r /grant:r "$($env:USERNAME):R"
This removes inherited permissions and grants only your user read access — required by OpenSSH on Windows.
